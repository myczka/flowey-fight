# Flowey Fight
This is just a command-line RPG fight against Flowey, in C++, for practice.

## Dependencies
As far as third-party goes, this project only relies on the miniaudio header. Previous dependencies that were part of another git repo of mine were not truly external dependencies as they were somewhat linked to the main source file. Now, those dependencies have become the engine for the project. I will provide documentation for the engine and for a general walk-through of the project in due time.

## Other Notes
You'll have to get your own sound effects, as most of them are from undertale, and the songs are recreations/remixes along with a completely original work.
