# Flowey Fight
This is just a command-line RPG fight against Flowey, in C++, for practice.

## Dependencies
As far as third-party goes, this project only relies on the miniaudio header. Previous dependencies that were part of another git repo of mine were not truly external dependencies as they were somewhat linked to the main source file. Now, those dependencies have become the engine for the project. I will provide documentation for the engine and for a general walk-through of the project in due time.

## Notes
The main progress is currently on the [modularize branch](https://github.com/myczka/flowey-fight/tree/modularize) and not here on master. I'm in the middle of a significant refactor right now and decided to work on a separate branch for the sake of it.

## Other Notes
You'll have to get your own sound effects, as most of them are from Undertale. The two songs here on the repo are a remix and an original work. Substitutes for all missing sounds will be added eventually.
